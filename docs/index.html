02 / THE SETUPONCE, THEN DONE

A small setup.
A very short send.

For Mac users who want the result on their phone, and for agents that should handle the clicks.

01
⌘

Install on your Mac

Build the small Swift app, then grant it Accessibility access once so it can select your AirDrop recipient.

02
◎

Choose your phone

Discover nearby devices and save the exact one you want. The default starts as none.

03
↗

Send anything supported

Pass a picture, file, or URL. Use --to when you want a different device for one send.

03 / TRY IT

Your next AirDrop
starts here.

macOS and an AirDrop capable device nearby. No extra iPhone app, server, or account for this tool.

TERMINAL
git clone https://github.com/BeritCheema/airdrop-cli.git
cd airdrop-cli && make install
airdrop-cli setup
airdrop-cli ~/Pictures/photo.png
