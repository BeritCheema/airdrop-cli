# Demo capture plan

The public page at https://beritcheema.github.io/airdrop-cli/ is the link sent in the real demo. The site's interactive terminal is illustrated; replace its “real footage” note with the edited clip after capture.

## Capture

1. Start the iPhone's built-in screen recording. Keep it unlocked on the Home Screen for 3–5 seconds.
2. With recording still running, tell the agent **“recording now”**. The agent runs the demo/send-site.sh script with ipon on the Mac and captures the Mac side at the same time.
3. Do not touch the iPhone while the AirDrop link arrives and opens the site. Leave the loaded page visible for 3–5 seconds, then stop recording.
4. Send the original screen recording file, untrimmed, so the AirDrop arrival can be synchronized with the Mac footage.

The screen should show the real AirDrop arrival and the site's headline. Turn on Do Not Disturb first if personal notifications might appear.

## Edit

- Start with the Mac command and CLI output.
- Cut to the phone as the link arrives and the site opens.
- End on the site headline, then the repo URL.
- Keep the final video around 15–25 seconds. Do not present the site's illustrated phone panel as real transfer footage.
